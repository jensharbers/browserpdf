# browserpdf
Lichttisch ist ein modernes, browserbasiertes Werkzeug zum Sichten, Bearbeiten und Neuordnen von PDF-Seiten. Mit einer intuitiven Drag-and-Drop-Oberfläche können Sie PDFs und Bilder einfach auf einen virtuellen "Tisch" laden, um sie zu sortieren, zu drehen, zu duplizieren, zu löschen oder zuzuschneiden.
